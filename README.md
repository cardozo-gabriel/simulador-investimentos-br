## 🇧🇷 Português

### 📝 Descrição
Este é um simulador interativo de renda fixa que permite comparar a rentabilidade líquida de diferentes ativos (CDB, LCI, Poupança e Tesouro Direto) ao longo do tempo. O projeto utiliza um backend em Python para cálculos precisos e um frontend dinâmico com gráficos modernos.

### 🚀 Funcionalidades
- **Comparação em Tempo Real:** Compare múltiplos ativos simultaneamente.
- **Gráficos Dinâmicos:**
  - Gráfico de barras agrupadas para comparação de evolução patrimonial mês a mês.
  - Gráfico de linha para visualizar o crescimento a longo prazo.
- **Personalização de Taxas:** Permite ajustar CDI, Rentabilidade de CDB/LCI e Taxas do Tesouro.
- **Layout Dashboard:** Design limpo e responsivo adaptado para desktop e mobile.

### 🛠️ Tecnologias
- **Backend:** Python + Flask
- **Frontend:** HTML5, CSS3, JavaScript
- **Gráficos:** Chart.js
- **Ícones:** Font Awesome

<a name="english"></a>
## 🇺🇸 English

### 📝 Description
This is an interactive fixed-income simulator that allows users to compare the net profitability of different assets (CDB, LCI, Savings, and Treasury Bonds) over time. The project uses a Python backend for precise calculations and a dynamic frontend with modern charts.

### 🚀 Key Features
- **Real-Time Comparison:** Compare multiple assets simultaneously.
- **Dynamic Charts:**
  - Grouped bar chart for month-to-month equity evolution comparison.
  - Line chart to visualize long-term growth.
- **Rate Customization:** Adjust CDI, CDB/LCI profitability, and Treasury rates.
- **Dashboard Layout:** Clean and responsive design adapted for desktop and mobile.

### 🛠️ Technologies
- **Backend:** Python + Flask
- **Frontend:** HTML5, CSS3, JavaScript
- **Charts:** Chart.js
- **Icons:** Font Awesome
